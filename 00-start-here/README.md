# Start Here

This folder has no resources of its own, it's a map to the rest of the repo, organized by goal instead of topic.

## Pick your path

### "I've never studied this before"
1. [`01-math-and-statistics`](../01-math-and-statistics/): just enough linear algebra, calculus, and probability to not be lost later.
2. [`02-ai-fundamentals`](../02-ai-fundamentals/): vocabulary, history, what's actually different between AI/ML/DL/LLMs.
3. [`03-machine-learning`](../03-machine-learning/): classical ML, still the foundation for intuition.
4. [`04-deep-learning`](../04-deep-learning/): neural nets and the road to transformers.

### "I can code, I want to build with AI, not research it"
1. [`05-large-language-models`](../05-large-language-models/): skip to the Articles/Tools rows, not the papers.
2. [`07-retrieval-augmented-generation`](../07-retrieval-augmented-generation/): grounding LLMs in your own data.
3. [`06-ai-agents`](../06-ai-agents/): tool use, planning, multi-step systems.
4. [`12-tools-and-frameworks`](../12-tools-and-frameworks/): keep this open as a reference the whole way.

### "I'm interested in generative media"
- [`08-image-models`](../08-image-models/) · [`09-video-models`](../09-video-models/) · [`10-speech-and-audio-models`](../10-speech-and-audio-models/)
- Prerequisite: [`04-deep-learning`](../04-deep-learning/) for the architectural basics (CNNs, diffusion, GANs).

### 🔬 "I already work in ML and want to specialize"
- Filter any section for Advanced tags and go straight to Papers.
- [`11-mlops-and-deployment`](../11-mlops-and-deployment/) if you're moving from research to production.
- [`papers/`](../papers/) for a running cross-topic feed of what's new.

### "I just want to understand AI, not build it"
- [`02-ai-fundamentals`](../02-ai-fundamentals/) alone will get you a working mental model without touching code.
