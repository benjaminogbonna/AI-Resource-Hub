# Notebooks

Runnable notebooks referenced from section READMEs, mirrored by section so the folder structure matches the topic structure:

```
notebooks/
├── 03-machine-learning/
├── 04-deep-learning/
├── 05-large-language-models/
├── 06-ai-agents/
├── 07-retrieval-augmented-generation/
├── 08-image-models/
├── 09-video-models/
└── 10-speech-and-audio-models/
```

A notebook lives here *and* gets linked from its topic section's "Notebooks & Code" list, the topic README is where you discover it, this folder is where you run it (e.g. via `git clone` + Jupyter, or opening directly in Colab).

Each notebook's entry in its section README should note whether it needs a GPU, runs on free-tier Colab, or requires an API key. See [CONTRIBUTING.md](../CONTRIBUTING.md) for how to add one.
