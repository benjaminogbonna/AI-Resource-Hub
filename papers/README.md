# Papers Log

A running, reverse-chronological log of notable papers across *every* topic in this repo, useful for "what's new" without checking every section individually. Each paper is also listed in its relevant topic section's Papers list; this is the cross-topic view.

Format:
```
- **[Title](https://arxiv.org/abs/xxxx.xxxxx)** (YYYY-MM) - `section` - one-line summary of the contribution.
```
